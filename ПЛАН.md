# План приложения «Конспекты» (архитектура)

Читать вместе с `design/ПРАВКИ.md` (все правки к дизайну) и `design/tokens.css` (дизайн-токены).
`design/preview.html` — только референс внешнего вида, код из него не копировать целиком.

## Технологии
| Что | Чем | Почему |
|---|---|---|
| Сборка | **Vite** | быстро, пользователь уже знает |
| UI | **React 18** + JSX | пользователь знает React |
| Стили | **SCSS-модули** + глобальный `tokens.css` | как в todo-main; все цвета/размеры только из токенов |
| Роутинг | **react-router-dom**, `HashRouter` | GitHub Pages не умеет SPA-роуты без хака; `#/v/...` работает везде |
| Состояние | **zustand** (+ `persist` в localStorage) | проще Redux, отметки и настройки сохраняются сами |
| Переводы | свой мини-модуль `i18n/` (uk / ru / en JSON + хук `useT`) | библиотека не нужна |
| Офлайн / «приложение на телефоне» | **vite-plugin-pwa** | кэширует сайт, данные и кадры |
| Облако (этап 6) | **Supabase** (`@supabase/supabase-js`) | отметки + очередь ссылок |
| Хостинг (этап 5) | **GitHub Pages** + GitHub Actions | бесплатно, автообновление при push |

## Данные
Исходники остаются в `~/Desktop/Claude/output/<название>/` (их делает `yt2txt.py` + Claude пишет `summary.json`).

Скрипт **`app/scripts/build-data.mjs`** (Node) собирает данные для сайта:
- для каждого видео с `summary.json` копирует в `app/public/data/v/<youtube_id>/`:
  `meta.json`, `summary.json`, `frames/*.webp`
  (transcript не копируем — сайту не нужен, экономим место);
- создаёт `app/public/data/index.json`: список видео
  `{ id, title, channel, duration, emoji, level, topics, counts: {sections, guides, terms, later}, lang }`.
- Видео без `summary.json` (ещё не обработаны Claude) — в списке с пометкой «в обработке», без страницы.

Папка видео в URL — **YouTube id** (латиница, стабильно): `#/v/MbPJWa6_FNM/notes`.

### Кадры для разделов
Сайт сам берёт кадры из `meta.frames` по времени: все кадры, у которых `section.t <= t < section.end`, максимум 6
(если больше — равномерно). Claude кадры не выбирает.

### Дополнения к формату summary.json (version 1 → 2)
- `"emoji"` — иконка видео для боковой панели;
- `"lang"` — язык конспекта (`"ru"`, `"uk"`, `"en"`);
- поле `frames` в разделах — больше не используется.

## Экраны (маршруты)
- `#/` — «Главное по темам» (этап 7; до этого — приветствие + список видео)
- `#/v/:id/:tab?` — страница видео, `tab` = `main | notes | guides | terms | later`
- `#/learned` — изученное, `#/later` — «на потом» из всех видео

## Структура кода
```
app/
  index.html
  vite.config.js
  scripts/build-data.mjs
  public/data/...                 ← генерируется, в git
  src/
    main.jsx, App.jsx
    styles/ tokens.css, base.scss, motion.scss
    i18n/ index.js, uk.json, ru.json, en.json
    store/ settings.js (тема, язык, свёрнута ли панель)
           progress.js (отметки шагов, изученные видео; потом синхронизация)
           queue.js    (очередь ссылок; потом Supabase)
    data/ useIndex.js, useVideo.js   (загрузка JSON, кэш)
    lib/  md.jsx (мини-Markdown), time.js, frames.js (кадры раздела)
    components/
      Shell/          каркас: сетка, адаптивность
      Sidebar/        список, сворачивание без прыжков, кнопка настроек
      Menu/           всплывающее меню: позиционирование с переворотом, blur, анимация пунктов
      Tooltip/        подсказка, всегда целиком на экране
      Segmented/      вкладки (как в первой версии макета, плавнее)
      Timeline/       «плёнка» видео + подсказка с 6 кадрами
      Island/         пилюля: свёрнутая / развёрнутая (ссылка, очередь, поиск, тема, язык, точка синхронизации)
      RightRail/      меняется по вкладке
      Checkbox/, CodeBlock/, Timecode/, Toast/, FrameGrid/
    pages/
      Home/, Video/ (MainTab, NotesTab, GuidesTab, TermsTab, LaterTab), Learned/, Later/
```

## Порядок работы (этап 4 — приложение)
1. **Каркас:** Vite + React, токены, i18n (uk по умолчанию), роутинг, `build-data.mjs`,
   страница видео с вкладками на реальных данных.
2. **Шкала времени** с подсказкой из 6 кадров + правая колонка по вкладкам.
3. **Боковая панель** (сворачивание без прыжков) + меню настроек (тема, язык) + меню/контекстные меню видео.
4. **Пилюля** (свёрнутая/развёрнутая), очередь — пока локально.
5. **PWA** (офлайн, установка на iPhone).
Дальше по общему плану: хостинг → Supabase → скилл «обработай видео» → остальные конспекты → «Главное по темам».

## Правила кода
- Цвета/размеры/скорости — только переменные из `tokens.css`.
- Никаких сдвигов раскладки: анимировать только `transform` и `opacity` (и `grid-template-columns` у каркаса).
- Все тексты интерфейса — через `useT()`, никаких строк в JSX.
- `prefers-reduced-motion` уважается.
- localStorage всегда в try/catch (может быть недоступен).
